# AI Chat Assistant

一个基于 Next.js 15 + TypeScript + Tailwind CSS 构建的 AI 对话应用。

## 技术栈

- Next.js 15 App Router
- TypeScript
- Tailwind CSS
- Vercel AI SDK
- Zustand
- React Query
- Prisma + PostgreSQL

## 功能特性（开发中）
